# 명령 기록 안내

이 폴더에는 실습 중 **실제로 실행한 명령과 실제 출력**을 기록합니다. 실행하지 않은 예시 명령은 실행 기록처럼 저장하지 않습니다.

## 기록 원칙

- 날짜와 목적을 알 수 있도록 `YYYY-MM-DD-description.md` 형식의 파일명을 사용합니다.
- 명령을 실행한 대상과 필요한 사전 조건을 함께 기록합니다.
- 명령(Command), 실제 출력(Output) 및 검증 판정을 구분합니다.
- 실패한 명령도 문제 분석에 필요하면 실제 오류와 함께 보존합니다.
- 구독 ID(Subscription ID), 비밀번호, 토큰(Token), SSH 개인 키(Private Key) 등의 민감정보는 저장하지 않습니다.
- 실제 숫자 Public IP 주소는 변경 가능하며 공개 저장소에 기록할 필요가 없는 운영 정보이므로 기록하지 않습니다.
- 공개할 필요가 없는 운영 정보나 민감정보를 제거할 때는 `[REDACTED]`와 같이 제거 사실을 알 수 있게 표시합니다.
- 관련 작업은 `PROJECT_LOG.md` 또는 `TROUBLESHOOTING.md`에서 이 파일로 연결합니다.

## 권장 형식

```markdown
# YYYY-MM-DD — 작업 제목

## 목적

## 실행 환경 또는 대상

## 실행한 명령

## 실제 출력

## 검증 결과

## 관련 증거
```
